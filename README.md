# 세계사 타임 레이스 — 설치 방법 (한 번만 하면 됩니다)

## 올릴 파일 4개 (같은 폴더에)
`index.html`, `questions.js`, `firebase-config.js`, (선택) `database.rules.json`

## 1. Firebase 프로젝트 만들기 (약 5분)
1. https://console.firebase.google.com → **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다)
2. 왼쪽 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: **싱가포르(asia-southeast1)** 추천 (한국에서 가장 빠름)
   - 보안 규칙: **테스트 모드**로 시작해도 되고, 아래 3번 규칙을 바로 붙여 넣어도 됩니다.
3. **프로젝트 설정(⚙) → 일반 → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 복사
4. `firebase-config.js` 를 열어 값을 붙여 넣기 (`databaseURL` 이 꼭 있어야 합니다)

## 2. 규칙 붙여 넣기
Realtime Database → **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 **게시**.
(방 코드를 아는 사람만 읽고 쓸 수 있고, 방 목록은 볼 수 없습니다. 테스트 모드는 30일 뒤 막히므로 꼭 교체하세요.)

## 3. GitHub Pages에 올리기
저장소에 파일을 올리고 Settings → Pages 에서 배포. 주소가 학생들이 접속할 주소입니다.

## 4. 수업 진행
1. 교사 컴퓨터(빔프로젝터): 주소 접속 → **교사: 방 만들기** → 큰 **방 코드**가 나옵니다.
2. 학생: 같은 주소 접속(코드가 들어간 링크 `?room=1234` 를 알려줘도 됩니다) → **번호+이름**, 캐릭터 고르기 → 방 코드 입력 → **수업 방 입장**.
3. 교사 화면에 입장한 친구 이름이 보이면 **▶ 시작** → 4.5초 뒤 동시에 출발!
4. 모두 들어오면 자동으로 **최종 결과**가 나옵니다. **⏹ 초기화** = 같은 방에서 새 라운드.
5. 수업이 끝나면 **← 나가기**를 두 번 눌러 방(데이터)을 삭제하세요.

## 문제 고치기
`questions.js` 의 한 줄이 한 문제입니다: `[시대번호, '질문', '정답', ['오답1','오답2','오답3'], '해설']`

## 참고
- 새로고침/끊김이 생겨도 같은 이름으로 다시 입장하면 달리던 위치에서 이어집니다.
- 이미 시작한 방에는 새 이름으로 들어올 수 없습니다 (이어하기만 가능).
- 학생 28명 기준 데이터 사용량은 한 판에 수십 MB 수준이라 무료(Spark) 요금제로 충분합니다.
